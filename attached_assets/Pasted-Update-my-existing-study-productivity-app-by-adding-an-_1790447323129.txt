Update my existing study/productivity app by adding an OPTIONAL YouTube-powered music feature.

The music feature must never be forced on users. Some users prefer complete silence while studying, so provide a clear Music ON/OFF control.

## YouTube Integration

Use:

- YouTube Data API v3 for music/video search
- Official YouTube IFrame Player API for playback

My YouTube API key will be stored securely in Replit Secrets as:

YOUTUBE_API_KEY

Do not expose the API key directly in frontend source code.

Create a backend endpoint such as:

/api/music/search?q=QUERY

The backend should securely call YouTube Data API v3 and return:

- videoId
- title
- channel/artist
- thumbnail

Prioritize music-related search results.

Do NOT download YouTube audio, convert videos to MP3, proxy YouTube streams, scrape YouTube, or use unofficial downloading libraries.

Use only the official YouTube embedded player.

## Music ON / OFF

This is very important.

Add a clearly visible setting:

🎵 Music
ON / OFF

Default:

Music OFF

When Music is OFF:

- Do not automatically play anything.
- Stop/pause any currently playing music.
- Hide/minimize the music controls.
- Do not automatically search or load unnecessary YouTube content.
- Study Mode should work completely normally without music.

Display a small message such as:

"Prefer silence? Keep music turned off for a distraction-free study session."

When Music is turned ON:

Show the compact music player and music search options.

Remember the user's preference using localStorage or the existing user database.

If the user selected Music OFF previously, keep it OFF the next time they open the app.

Never autoplay music when the app starts.

## Distraction-Free Mode

Add an additional quick action:

When activated:

- Immediately pause music.
- Disable autoplay.
- Minimize/hide music controls.
- Keep the timer and all study features running.
- Do not delete the user's queue, favourites or music preferences.

The user should be able to turn music back on whenever they want.
