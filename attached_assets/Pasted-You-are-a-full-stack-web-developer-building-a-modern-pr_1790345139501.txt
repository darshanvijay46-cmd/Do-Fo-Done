You are a full-stack web developer building a modern, production-quality personal productivity application called **FocusFlow**.

Your task is to build a complete, functional web application—not a mockup or visual prototype. Every interactive element must work. All data must persist and interconnect. All calculations must be real, derived from actual user activity.

---

## CORE PURPOSE

FocusFlow helps students and young professionals organize their entire day in one place while making productivity feel interactive and enjoyable rather than like a boring task manager.

The standout workflow is:
1. Create tasks as sticky notes
2. Drag sticky notes onto a timeline
3. Automatically schedule them
4. Start a focus session with a chosen study environment
5. Listen to focus music and track time
6. Complete the task
7. Automatically update daily progress and analytics

---

## TECHNICAL CONSTRAINTS

**Target Environment:**
- Modern browsers only (Chrome, Firefox, Safari, Edge—latest 2 versions)
- ES6+ JavaScript support assumed
- Assume modern browser APIs (drag-and-drop, Web Audio, Notifications, localStorage/IndexedDB)

**Connectivity Model:**
- Hybrid approach: Core features (tasks, scheduling, timers, focus sessions, data storage) work completely offline
- Music streaming and browser notifications are optional enhancements that gracefully degrade when offline
- Do not block or error if music or notifications fail; the app remains fully functional

**Audio Implementation:**
- Integrate real audio for the Study Music player using one of:
  - Royalty-free audio files hosted locally in the project or on a CDN
  - Free public APIs (e.g., Spotify Web API with proper attribution, YouTube Data API, or similar)
  - Do not use placeholder audio or pretend music is playing if no source exists
- Music must continue playing uninterrupted when the user navigates between pages or sections

## STICKY NOTE TASK SYSTEM

**Creating Sticky Notes:**
- Allow users to create tasks as digital sticky notes
- Each sticky note contains: Task name, Category, Priority, Estimated duration, Optional deadline
- Sticky notes have subtle category-based colors (not bright colors)
- Sticky notes can be Created, Edited, Deleted, Moved, and Completed

**Sticky Note Animations:**
- When created: Subtle pop/fade animation
- When picked up: Slightly enlarge, add stronger shadow, slightly rotate, appear lifted
- When dragged: Move smoothly with the pointer
- When completed: Animate subtly and display as completed
- All animations should be polished but fast, never distracting

## DRAG TASKS ONTO SCHEDULE (CORE FEATURE)

**Functionality:**
- Allow sticky notes to be dragged directly onto the daily schedule timeline
- When a sticky note is dropped on a time slot, automatically create a scheduled activity using the task's estimated duration
- Example: Dragging "Practice Java – 1 hour" onto "7:00 PM" creates "Practice Java 7:00 PM – 8:00 PM"

**Drop Interactions:**
- While dragging over the timeline, highlight available time slots
- Display a visual preview of where the task will be placed
- When dropped, animate the task into the selected time slot
- Show a small toast notification: "Task scheduled for 7:00 PM"

**Conflict Detection:**
- Detect overlapping activities
- Display: "This time overlaps with another activity"
- Offer options: Choose another time, Replace existing activity, or Cancel
- Never silently overwrite another activity

- Controls: Start, Pause, Resume, Reset, Finish Session
- Timer must continue accurately when navigating between pages
- When a session finishes, store: Task, Category, Date, Start time, End time, Total duration

**Study Music Player:**
- Compact, non-distracting player
- Provide categories: Lo-fi, Piano, Rain, Cafe, Nature, White Noise
- Controls: Play, Pause, Previous, Next, Volume

- Do not pretend music is playing if no audio source exists

**Study Environments:**
- Provide a "Change Environment" option with visual backgrounds:
  - Cozy Study Room
  - Rainy Window
  - Library
  - Night City
  - Forest
  - Minimal Dark Room
  - Cafe
- Use smooth fade transitions when changing environments
- Add overlays if needed to maintain text readability

- Never allow backgrounds to reduce readability

**Study Notes:**
- Allow users to create, edit, and delete quick notes within Study Mode

**Study Workflow Integration:**
