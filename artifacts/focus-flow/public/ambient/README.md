# Ambient audio assets

No verified, licensed ambient recordings are currently included in this project. The Study page therefore shows each environment's intended soundtrack as unavailable and does not start fabricated or missing audio.

To enable a soundtrack, add a licensed audio file to this directory and set that environment's `asset` value in `src/lib/ambient-audio.ts` to its public path (for example, `/ambient/rain-on-glass.mp3`). Keep the source/license information with the asset before shipping it. The existing YouTube MusicDock is a separate player and should remain unchanged.

Missing recordings: Rain on Glass, Library Hush, Forest Morning, Night Train, Coffee Shop, Open Window, and Deep Work.
